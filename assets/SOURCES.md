# Harness icon sources

All assets are `512 × 512` PNGs. Monochrome marks use the source icon library's canonical avatar treatment (brand background plus contrasting foreground) so they remain legible in Discord.

- `agy.png`, `amp.png`, `claude.png`, `cline.png`, `codex.png`, `copilot.png`, `cursor.png`, `devin.png`, `gemini.png`, `grok.png`, `hermes.png`, `kilo.png`, `kimi.png`, `kiro.png`, `mastracode.png`, `opencode.png`, `pi.png`, and `qodercli.png`: [Lobe Icons](https://github.com/lobehub/lobe-icons), npm package `@lobehub/icons` 5.14.0.
- `omp.png`: Pi mark from Lobe Icons; OMP is a Pi fork ([oh-my-pi](https://github.com/can1357/oh-my-pi)).
- `droid.png`: [Factory Droid favicon](https://raw.githubusercontent.com/Factory-AI/factory/main/docs/favicon.svg).
- `maki.png`: [Maki 512 px app icon](https://raw.githubusercontent.com/tontinton/maki/main/site/android-chrome-512x512.png).
